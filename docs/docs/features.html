Features overview

Everything the app side does, grouped by area. Screen Layout, Save States, Controls and Themes each get their own page — this one is the map.

On this page

Library & importing

  • Library & importer — import your own game dumps.
  • keys.txt handling — drop a keys.txt from your own Wii U into the Files app or import it in Settings; nothing is bundled.
  • Decrypt-to-Files and WUA — save a decrypted copy to Documents/Decrypted/<gameID>/ as files or one WUA. Your original is not changed.
  • DLC and updates — import a DLC or update dump; it is matched to its game automatically. Remove it with a long-press.
  • Graphic packs — browse and toggle packs from Documents/mlc/graphicPacks/; drop in a folder with its own rules.txt, the same layout desktop Cemu uses.

On-screen play

  • The measured Wii U GamePad, hide-controls, comfort controls, and 20 controller skins.
  • Melo-Controller — an alternative touch pad with its own layout editor, as a toggle.
  • Screen Layout — Single Screen, Adaptive (both screens) or Both Screens (GamePad Top Right), plus output to a second display.
  • Save States — 4 numbered slots per game, alongside your normal in-game saves.

Look & feel

  • 31 app icons and matching themes — three are unlocked with a code, everything else is free.

Wii U Menu (experimental)

MuffinEMU can start the Wii U Menu, the console's own home screen, and the Menu can launch the games in your library. This is experimental and has not been confirmed on a device yet, so expect crashes.

The files must come from your own Wii U. Dump them with Dumpling. MuffinEMU includes none of them and never downloads any.

Import them in Settings → Wii U Menu:

  • Import Wii U Menu — pick the dump folder. It can be the package folder (the one containing mlc01 and cafeLibs), an mlc01 folder, a sys folder, a cafeLibs folder, or the Menu's own title folder. Files are merged one by one; anything that gets replaced is saved to Documents/mlc/import-backup-… first, and your saves are never replaced.
  • Import console files — pick otp.bin and seeprom.bin. They are only needed for online features; the Menu may start without them.

Where they end up, in the app's Documents folder (visible in the Files app):

  • mlc/mlc01/sys/title/00050010/10040X00 — the Menu (10040000 Japan, 10040100 USA, 10040200 Europe).
  • mlc/mlc01/sys/title/0005001b — shared data (fonts, Mii) the Menu needs, along with 00050030 and 0005000e from the same dump.
  • mlc/cafeLibs/ — drmapp, erreula, nn_sl, nsyskbd, snd_user, snduser2 and swkbd (.rpl).
  • mlc/otp.bin and mlc/seeprom.bin.

Settings shows which of these are present. Once the Menu is installed, a Wii U Menu tile appears at the top of the library; if something the Menu can't start without is missing, tapping it tells you what.

Games from your library (Documents/Roms: folders, .wua, .wux, .wud) are added to the Menu's title list while the Menu runs, so they can show up in it and launch from it. Encrypted games still need your keys.txt. Games you installed into mlc/mlc01/usr/title show up too.

Diagnostics

  • In-app launch log — shows the log live while a game starts, and tells you if lines were dropped.
  • Crash log — progress is written to Documents/CemuCrashLog.txt as the app runs, so it survives a hard crash. Attach it to bug reports.

Under the hood

The renderer is Metal, with an optional Vulkan (MoltenVK) path. On GPUs without mesh shader support, such as the A12Z, draws that need geometry shaders are skipped, and BC-compressed textures are decoded on the CPU.

The CPU side runs a multi-core PowerPC interpreter with a predecoded instruction cache; an AArch64 recompiler is present and takes over when a JIT enabler is attached (see JIT requirements).

Builds include a selection of upstream Cemu fixes plus MuffinEMU's own.
