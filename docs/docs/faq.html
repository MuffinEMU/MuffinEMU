FAQ

Short answers to the questions that come up most.

What is MuffinEMU?

A free, open-source Wii U emulator for iPhone and iPad, based on Cemu.

MuffinEMU (also written Muffin EMU or Muffin-EMU) runs on iOS and iPadOS 15 or later. It runs a Cemu-based core with a Metal renderer, an on-screen GamePad measured from the real hardware, and the recompiler wherever iOS allows it. You bring your own games and keys.

Is this the official MuffinEMU website?

Yes. muffinemu.github.io/MuffinEMU is the official MuffinEMU website.

MuffinEMU's official source code and releases are on GitHub at github.com/MuffinEMU/Muffin-EMU. The SideStore, AltStore and TrollStore sources in the installation guide install the IPAs published there.

Is MuffinEMU related to Go Go Muffin?

No.

MuffinEMU is a Wii U emulator for iPhone and iPad. It isn't related to the mobile game Go Go Muffin or to the MuMu emulator.

Do I need to own a Wii U?

For encrypted retail games, yes.

You need keys.txt dumped from your own console. Homebrew does not need it. MuffinEMU does not include keys.

Which install method should I use?

SideStore, AltStore or LiveContainer for a normal install; TrollStore or a jailbreak for embedded JIT entitlements.

See Installation for the full breakdown of which IPA goes with which installer.

Does it support every Wii U game?

Some games boot and play, many haven't been tried.

Not confirmed on hardware

Some games boot and play, many haven't been tried. Compatibility hasn't been catalogued yet.

Does Splatoon work?

It is set up to, but it has not been confirmed on hardware.

Not confirmed on hardware

Splatoon (USA, Europe and Japan) runs on its standard settings, and motion aiming, the GamePad touchscreen and the offline modes are in place. None of it has been played through on a device yet.

  • Aiming. Motion aiming is on by default; tilt and turn the device like the GamePad. Settings > Motion & Aiming has sensitivity and a recentre button. For stick-only aiming, turn it off there and switch off Motion Controls in the game's own options. See Motion aiming.
  • No motion sensors. A device without a gyroscope shows a note in Settings > Motion & Aiming, and the GamePad simply stays still. Switch off Motion Controls in the game's own options and aim with the right stick.
  • Controls. The first time Splatoon starts, MuffinEMU turns on Add analog sticks so you can move and steer. If you have already set that option yourself, it is left as you chose it.
  • Map and super jump. These are on the GamePad screen. The first time Splatoon starts, the screen layout shows both screens: side by side on an iPad, with the GamePad as a small inset on an iPhone. Change it in Settings > Display > Screen Layout. Tap a teammate on the map to super jump; hide the on-screen controls first if they cover it.
  • Offline. Octo Valley, the Battle Dojo and Inkopolis Plaza do not need a network connection. Online battles are not covered.
  • Performance. Splatoon is CPU-heavy. The default resolution is chosen for your device's screen and memory, and a single emulated CPU core is the right starting point on a fanless iPad or an iPhone. Lower Resolution in Settings > Graphics if it struggles.

Can I use a physical controller?

Yes, MFi and Bluetooth controllers work.

They work, but haven't been tested across many models.

Is there a paid version?

No. MuffinEMU is free.

Three of the 31 app icons (Diamond Ice, Gold VIP, Holographic) unlock with a code; everything else has no restrictions. See Themes & Icons.

What license is MuffinEMU under?

The IPA as a whole is distributed under GPL-3.0.

MuffinEMU's own source is MPL-2.0, like Cemu. Because Melo-Controller (GPL-3.0) is linked into every build — whether or not its toggle is on — a MuffinEMU IPA as a whole is GPL-3.0, with the MuffinEMU repository as its source.

Does dual-screen TV output work?

Not confirmed yet.

It hasn't been tested with a second display attached — see External display routing.
