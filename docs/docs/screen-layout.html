Screen Layout

The Wii U has two screens: the TV and the GamePad.

On this page

  • On this device's screen
  • External display routing

The Wii U has two screens. On iPhone and iPad they share one screen, or the TV can go to a second display.

Screen Layout (this device's own screen)

Settings > Display > Screen Layout.

ModeWhat it does
Single Screen Only the selected screen renders. A swap button switches between TV and GamePad.
Adaptive (Both Screens) TV and GamePad automatically adjust: stacked in portrait, side by side in landscape.
Both Screens (GamePad Top Right) A small GamePad appears at the top right in its own column beside the TV view.

Single Screen is the default. While it is active, a "Show Swap Button (TV ⇄ Pad)" toggle controls whether the in-game swap button appears — it is the only mode where exactly one screen is visible at a time, so it is the only one where swapping means anything.

External display routing

The TV screen can also go to a second display, when one is connected.

Not confirmed on hardware

Output to a second display hasn't been tested with a display attached. Connecting one is expected to mirror the TV screen only.
